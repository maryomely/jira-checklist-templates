# Smart Checklist Markdown import demo

`smart-checklist-markdown-import.gif` was supplied by the repository owner and is included unchanged. It shows entering Markdown in Smart Checklist and displaying the formatted checklist, including an embedded image.

The GIF is 1280 × 640 pixels, loops, and runs for approximately 14 seconds. The README displays it at 760 pixels wide, with a link to open it at full size.

For exact syntax, use the [formatting guide](../../skills/write-jira-checklist/references/formatting-guide.md). The separate [live import results](../import-validation-2026-11-27.md) describe the repository template tests.
