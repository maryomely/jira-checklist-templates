## Vendor security compliance checklist
- Check the Security Tab
- Identify Data Residency
- Check the time of the last update
- Review legal documentation
> * Privacy Policy
> * Security Policy
> * Service agreement
- Is the app Cloud Fortified?
- Is the app a member of the Bug Bounty program?
- Reach out to the vendor
> * Request information on data transmission and data storage using [the questionnaire](data_storage_questionnaire_url)
> * Request information on security mechanisms using [the questionnaire](security_questionnaire_url)
