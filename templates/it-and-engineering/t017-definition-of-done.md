# Definition of Done (DoD)
- Code is implemented according to `acceptance criteria`
- Approve with @TeamLead
- Unit tests are **written and passing** (coverage > 80%) – see [:book: Testing Guidelines](testing_guidelines_url)
- QA/testing completed by @QA
- No _critical_ or _high-severity_ bugs – verified in [:ladybug: Bug Tracker](bug_tracker_url)
- Code reviewed (PR approved)
- Feature flags configured (if needed :point_up:)
> Note: Use LaunchDarkly for all new flags – [:gear: Feature Flag Docs](feature_flag_docs_url)
- Documentation updated (if needed :point_up:)
- Release notes added by @PM
- [dueDate="final_sign_off_date"] Review with A-Team – `final sign-off required`
