# Project Kickoff Template - Checklist
## Scope planning
- Confirm project goals and success criteria
- Define the key project deliverables and milestones
- Identify stakeholders and the project owner
## Documentation & Knowledge Sharing Session Preparation
- Schedule a kick-off meeting
- Prepare the project brief or Confluence page
- Share relevant documentation
## Jira Setup
- Create a Jira project or epic
- Set up the necessary boards and workflows
- Assign initial team members
- Add epics/work items for the key milestones
## Team Tools & Activities Setup
- Define communication channels (Slack, email, Jira comments)
- Schedule regular check-ins or standups
- Share the project timeline with the team
